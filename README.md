# Your Data, Your Call

An independent, Canada-first digital rights education website, designed especially for young Canadians.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. GitHub Pages will build the Jekyll site. Check the **Actions** tab for deployment status.

The site is configured for the project URL: https://sebbuck.github.io/Your-Data-Your-Choice/

## Local preview
Install Ruby and Bundler, then run `bundle install` and `bundle exec jekyll serve`.

## Editorial and privacy principles
- Plain-language explanations, not fear-based messaging.
- Cite primary sources for legal and factual claims; show dates and limitations.
- No accounts, advertising trackers, or unnecessary collection built into the site.
- Interactive learning tools should run locally in the visitor's browser.
- Educational information is not legal advice.

## Before launch
Review legal content against current legislation and regulator guidance; test keyboard and screen-reader accessibility; check all links; and verify GitHub Pages deployment and hosting behaviour.
